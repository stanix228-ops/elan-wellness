# ÉLAN Wellness — Премиальная массажная студия & Booking Engine

> **Live Demo:** [https://stanix228-ops.github.io/elan-wellness/](https://stanix228-ops.github.io/elan-wellness/)  
> **Концепция:** Бутик-отель · Private Wellness · Натуральные материалы · Cormorant Garamond · Онлайн-запись

Готовое цифровое решение для премиальной массажной студии, СПА-пространства или велнес-салона: гость самостоятельно знакомится с философией, выбирает ритуал и мастера, указывает удобное время в интерактивном календаре и сохраняет бронирование в свой календарь.

---

## 🌿 Ключевые особенности

* **Единый конфигурационный движок:** Название бренда, контакты, валюта (`₸`), услуги, мастера, цены и тексты вынесены в `src/config/studioConfig.ts` — сайт легко адаптируется под любого заказчика за несколько минут.
* **Полноценная онлайн-запись (6 шагов):**
  1. *Выбор услуги* (с фото, длительностью, описанием и ценой)
  2. *Выбор мастера* (конкретный специалист или «Любой свободный специалист»)
  3. *Интерактивный календарь* с блокировкой прошедших и нерабочих дней
  4. *Сетка слотов времени* (утро, день, вечер с индикатором занятости)
  5. *Контактные данные* (маска телефона `+7`, валидация, атмосфера сьюта, согласие на обработку данных)
  6. *Подтверждение и Success State* (номер записи `#ELAN...`, сохранение в Apple Calendar / Google Calendar через `.ics`)
* **Фирменный дизайн и типографика:**
  * Serif: *Cormorant Garamond* (крупная антиква)
  * Sans: *Manrope* (чистый геометрический гротеск)
  * Палитра: Cream `#F7F4ED`, Surface `#FFFCF6`, Olive `#667052`, Accent `#C6B99F`, Text `#292A23`
* **Mobile-First UX:**
  * Плавающая нижняя панель (Sticky Bar) с быстрым доступом к записи
  * Touch targets от 44–48px
  * Адаптивное меню-шторка (Sheet)
* **Доступность (A11y):**
  * Skip-link, клавиатурная навигация, фокус-ринги, семантический HTML5.

## 🛠 Технологический стек

* **Фреймворк:** React 19 + TypeScript
* **Сборка:** Vite
* **Стилизация:** Tailwind CSS + Radix UI Primitives
* **Иконки:** Lucide React
* **Календарь:** Генерация RFC 5545 `.ics` + Google Calendar API
* **Деплой:** GitHub Actions + GitHub Pages

## 📂 Структура проекта

```text
src/
├── components/
│   ├── booking/            # Пошаговая онлайн-запись, сертификаты, правовые модалки
│   ├── sections/           # Секции лендинга (Hero, WhyUs, Services, Specialists, Space, etc.)
│   └── ui/                 # Доступные базовые компоненты (Accordion, Button, Calendar, Dialog)
├── config/
│   ├── studioConfig.ts     # Единая мастер-конфигурация студии (источник правды)
│   ├── brand.ts            # Адаптер бренда
│   ├── services.ts         # Адаптер каталога услуг
│   ├── specialists.ts      # Адаптер мастеров
│   └── tokens.ts           # Дизайн-токены
├── lib/
│   ├── booking.ts          # Логика слотов, валидация, генерация номеров
│   ├── calendarExport.ts   # Экспорт в .ics и Google Calendar
│   └── utils.ts            # Форматирование валют и объединение классов
└── main.tsx
```
