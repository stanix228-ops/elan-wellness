## 2. Typography System

- **Heading / Editorial Serif:** `Cormorant Garamond` (weights 400, 500, 600, italic 400)
  - Крупные редакционные заголовки, плавная антиква, `line-height: 1.06–1.15`, `letter-spacing: -0.02em`.
  - Без тотального uppercase в заголовках, деликатное использование курсива только для смысловых акцентов.
- **Body & UI Sans:** `Manrope` (weights 300, 400, 500, 600)
  - Чистая современная геометрия для описаний, навигации, цен, расписания и интерактивной формы онлайн-записи.
  - Микро-подписи (`MASSAGE · BODY · MIND`): `0.75rem`, `letter-spacing: 0.18em`, uppercase только для eyebrow-тегов.

## 3. Composition & Layout Principles

- **Много воздуха:** секционные отступы `py-20 md:py-32`, просторные внутренние поля, читаемая длина строки (`60–68ch`).
- **Асимметричная редакционная вёрстка:**
  - Hero: крупная архитектурная композиция с асимметричным кадрированием, вынесенной редакционной карточкой и атмосферой утреннего света в кабинете.
  - Каталог услуг: редакционный интерактивный каталог с фильтрацией по категориям и крупной типографикой вместо 6 одинаковых SaaS-карточек.
  - Пространство: асимметричная архитектурная галерея из 5 кадров с разным соотношением сторон и подписями материалов (натуральный лён, тёплый травертин, массив дуба, рассеянный свет).
- **Скругления и линии:**
  - Тонкие разделители `1px solid #E5E0D5`.
  - Крупные радиусы (`rounded-2xl` / `rounded-[28px]`) только для ключевых фотографий и модальных поверхностей; строгие или мягкие (`rounded-lg` / `rounded-full`) для кнопок и контролов.
- **Запрещено:**
  - Никаких эмодзи вместо векторных SVG-иконок (`lucide-react`).
  - Никаких кислотных цветов, случайных градиентов и тяжёлых размытых теней.
  - Никаких фальшивых рейтингов («5.0 ★ из 428 отзывов»), медицинских обещаний или ложного подтверждения записи от сервера.
